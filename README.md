# Task 1 – Sales Performance Dashboard

## Overview
This project was completed as part of the Future Interns Data Science & Analytics Internship. The objective was to analyze sales data and build an interactive dashboard to monitor revenue, profit, orders, and business growth trends.

## Tools Used
- Power BI
- Excel / CSV Dataset
- Data Cleaning
- DAX Measures

## Dashboard Features
- Total Sales KPI
- Total Profit KPI
- Total Orders KPI
- Monthly Sales Trend
- Profit by Category
- Regional Performance Analysis
- Top Products
- Interactive Slicers

## Key Insights
- Identified top-performing products and categories.
- Compared sales across regions.
- Tracked monthly growth trends.
- Highlighted profit contribution areas.

## Outcome
Built a professional business dashboard to support data-driven decision making.
